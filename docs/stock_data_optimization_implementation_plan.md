### 问题详情：ISS-004 AKShare API 连接中断

**错误信息**:
```
('Connection aborted.', RemoteDisconnected('Remote end closed connection without response'))
```

**根本原因分析**:
1. AKShare API 服务器可能有限流保护
2. 网络连接不稳定
3. 请求超时配置不足

**解决方案**:
1. ✅ 创建 `EnhancedAKShareCollector` 类
2. ✅ 实现指数退避重试机制（`retry_with_backoff` 装饰器）
3. ✅ 增加请求间隔控制（避免触发限流）
4. ✅ 增加超时配置（默认30秒）
